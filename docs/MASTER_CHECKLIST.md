- [ ] **Customs declaration for goods** — declare both MacBook Pros + any new electronics; carry purchase invoices to defend "personal use" against the NPR 100 new-goods tax rule.
- [ ] **TIMS card** — only if you plan any trekking. Muktinath darshan by road does *not* need TIMS, but if you walk beyond, get one.
- [ ] **ACAP permit (Annapurna Conservation Area)** — required for entering the Mustang/Annapurna region beyond Beni. NPR 3,000 per person for foreigners; SAARC nationals (Indians) NPR 1,000. **Buy online at `https://epermit.ntnc.org.np/` OR at the Pokhara/Simpani counter BEFORE driving up.** At-checkpost surcharge is *double* (verified 2026-05-04 by Claude Code crawl). Aadhaar OR Voter ID accepted for Indian SAARC.
- [ ] **Restricted Area Permit (Upper Mustang)** — *only if going beyond Kagbeni / Lo Manthang*. Lower Mustang (Muktinath, Jomsom, Kagbeni) is open zone — only ACAP needed.
