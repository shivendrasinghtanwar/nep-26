# Packing strategy — Thar Roxx

> Where things go in the SUV. Decided once, before 9 May. Saves arguments at every hotel.

## Zones

```
                 [Front]
   ┌──────────────────────────────────┐
   │  Glovebox: documents set #1      │
   │  Driver door: phone, sunglasses  │
   │  Centre: power bank, charging    │
   │  Co-driver door: snacks          │
   ├──────────────────────────────────┤
   │  REAR ROW                        │
   │  Wife seat: day bag, water       │
   │  Other seat: pillow / cushion    │
   ├──────────────────────────────────┤
   │  BOOT (top tray)                 │
   │  - Laptop bag (both MacBooks)    │
   │  - Documents set #2 (ziplock)    │
   │  - Medical kit                   │
   │  - Camera                        │
   ├──────────────────────────────────┤
   │  BOOT (lower / floor)            │
   │  - Main suitcases (×2)           │
   │  - Tool kit                      │
   │  - Tow rope, jumper cables       │
   ├──────────────────────────────────┤
   │  ROOF or REAR-MOUNTED            │
   │  - 10 L jerrycan (legally empty) │
   │  - Spare tyre                    │
   └──────────────────────────────────┘
```

## Why this layout

- **Both document sets** — one in glovebox, one in boot ziplock — survives a single-bag loss or a wet boot.
- **Laptops always in boot tray** — never visible from outside. Lock the boot. Hotels with valet: take laptop bag to room.
- **Medical kit reachable without opening main suitcases** — altitude headaches at Muktinath aren't going to wait.
- **Tow rope + tools at floor level, not top** — they're heavy; centre of gravity matters in Mustang switchbacks.
- **Jerrycan on roof or rear-mounted** — fuel fumes don't enter cabin.

## What stays out of the car

- Passport originals — wear in body pouch when crossing border.
- Cash — split: 60% in driver wallet, 30% in wife purse, 10% in hidden vehicle compartment.
- Spare key — separate bag, kept by wife, NOT in glovebox.

## What rides in the cabin even on driving days

- Phone + chargers
- Water bottles (one each)
- Sunglasses
- Light snacks (nuts, biscuits)
- Day bag with one set of warm layer + sunscreen
- Wet wipes + tissues
- Bin bag for trash
